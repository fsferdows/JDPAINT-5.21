# 2D Vector & 3D Relief Defect Taxonomy

Map observed visual symptoms and `diagnose_2d3d.py` metrics directly to verified root-cause locations, generalized fixes, and protected invariants.

| Defect ID | Visual Symptom / `DEFECT_FLAG` | Root Cause File & Symbol | Generalized Algorithmic Fix | Guarded Invariant |
| :--- | :--- | :--- | :--- | :--- |
| **`WM-ERASE`** | Missing interior petals, rectangular black cutouts in `Raised Relief Motifs`, `subject_wm_px > 0` | `cad-kernel/vision_worker.py` -> `_inpaint_watermarks` | Require bright pure graphic ink (`r >= 145`, `r - max(g,b) >= 115`, `g < 0.34*r` for crimson; `b >= 125`, `b - max(r,g) >= 42`, `r < 0.65*b` for blue) and isolate dark sub-text strictly inside outer banner strips (`<14%` top or `>86%` bottom). | Wood carvings with warm amber/mahogany channels (`g/r >= 0.38`) have `subject_wm_px == 0`; footer brands still get inpainted. |
| **`SQUARE-POCKET`** | `3x3` square pixel blocks inside dark flower centers or low cubic handle ratio (`cubic_ratio < 0.75`) | `cad-kernel/jdpaint_rust_core/src/main.rs` -> `detect_corners_and_fair` | Pin corners only when `n >= 44`, `k >= 5`, turning angle sharp (`cs < thresh`), and **both** incoming/outgoing arms are locally straight (`arm_max_perp <= 0.85`). | `cargo test::test_rosette_no_square_corners_keeps_cubic` passes; `motif_cubic_ratio >= 0.75`. |
| **`ZIGZAG-FACETS`** | Sawtooth polygon facets along smooth leaves or petals | `cad-kernel/jdpaint_rust_core/src/main.rs` -> `fit_span_schneider`; `vision_worker.py` -> `_trace_field_rust` | Require `n >= 8 && chord_len >= 16.0` with tighter `straight_tol * 0.55` before collapsing curves to lines; use `(5, 5)` Gaussian pre-smooth when `smooth_sigma >= 0.80`. | `cargo test::test_square_with_hole_straight_line_collapse` preserves straight frames (`<= 6` nodes). |
| **`MERGED-BLOBS`** | Adjacent rose petals fuse into huge outer shells (`max_ring_pts > 160`) | `cad-kernel/vision_worker.py` -> `_extract_wood_relief_vectors` | Do not run `MORPH_CLOSE` on `raised_raw` after subtracting `crevice_cut`; cut creases with fine BlackHat (`bh_fine_crev >= bh_fine_fl * 0.94`) and `MORPH_OPEN(3x3)` only. | Individual leaves, berries, and spiral rose petals separate cleanly. |
| **`DARK-PETAL-LOSS`** | Shadowed floral bowls or dark ribbed petals skipped (`mid_span` / `bot_span` drop or missing contours) | `cad-kernel/vision_worker.py` -> `_extract_wood_relief_vectors`, `_equalize_illumination_retinex` | Normalize multi-scale `wh_petal` against local carving envelope `env_wh = GaussianBlur(wh_petal)` (`wh_score`) and keep fine BlackHat `crevice_cut` thin (`ker_f`). | Low-light recovery convergence stays `>= 96%` (`min_tile >= 86%`). |
| **`GRAIN-TICKS`** | Short vertical dashes floating inside blank wood panels or bare plank margins (`floating_grain_cnt > 4`) | `cad-kernel/vision_worker.py` -> `_extract_straight_cad_lines`, `filter_mask_components` | Prune unanchored short verticals (`ln < 0.15*vh`) lacking **both** top+bottom rail anchors OR `>= 2` equal-length fluted pilaster peers (`ov_y >= 0.72 * max_len`); reject slender vertical needle slivers in masks. | Full rectangular stiles, corner boxes, and fluted pilasters stay intact (`panel_grain <= 2`). |
| **`CRATER-3D`** | Stained dark flowers sink into flat black/dark craters in 3D `Solid` clay (`sub_patch_span < 0.25`) | `cad-kernel/vision_worker.py` -> `_solve_planar_relief_heightmap`; `jdpaint-mac/src/relief/asset3DEngine.js` | Bound `z_macro` to `[0.28..0.86]`; sculpt multi-scale `White TopHat` (`+Z`) minus `BlackHat` (`-Z`) via Rust Screened Poisson + edge-preserving bilateral (`sigmaColor=0.07`); keep `taubinPasses <= 1` for planar neural relief. | Dark floral rosettes rise proudly (`rosette_peak >= 0.46`, `span >= 0.26`). |
| **`WM-BUMP-3D`** | Faint watermark embossing along top/bottom 3D margin | `cad-kernel/vision_worker.py` -> `handle_reconstruct_3d`, `_solve_planar_relief_heightmap` | Run `_inpaint_watermarks` even when `roi is None` (if `not is_logo`), resize `wm_mask_3d` with crop, and zero `sculpt_raw` inside dilated `wm_mask`. | Zero raised watermark ridges along bottom frame in `Solid` view. |
| **`DEAD-3D-LAYERS`** | 2D Layers stay `2D` (`enabled: false`), 3D preview stays low-res `384` or shows needles/spikes (`active_3d_ratio == 0`) | `jdpaint-mac/src/main.js`, `vectorPuffEngine.js`, `viewport3D.js` | Match `'Raised Relief Motifs'` + `'Raised Petals & Motifs'`; enable semantic layer relief (`smooth add 0.72mm` motifs, `smooth sub 0.45mm` grooves, `flat max 0.45mm` frame); lower `strokeHalfWidthMm` min to `0.35mm`; apply 2-pass bilateral Taubin fairing; dynamically upgrade `reliefEngine.setResolution(512)` with `updateMeshHeights()` auto-rebuild & `_emitStats()`. | Test 4 (`hole=0`), Test 8 (`384` init & flat plaque `0.55`) stay passing while UI renders `522,242` live layered faces. |
| **`BREP-STEP-FAIL`** | Open edges, non-manifold shells, or failed OpenCascade `.STEP` export | `cad-kernel/brep_builder.py`, `cad_bridge_server.py` | Load `b123d-repair` and `agentcad`; inspect failing geometry coordinates (`BRepCheck`) and re-sew/loft clean planar solids. | `e2e_brep_bridge.py` (`Valid=true`, ISO-10303-21 `.STEP`) passes. |
